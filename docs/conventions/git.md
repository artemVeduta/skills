# Git workflow

- Default branch is `main`; remote is `github.com/artemVeduta/skills.git`.
- Commit subjects are descriptive prose (see `git log` for the established
  style), not conventional-commit prefixes.

## Rationale

A single default branch and a consistent prose commit style keep history
readable for a small personal skills library without ceremony.
