# Glossary

Domain terms used across the repository. One defined term per file.

- [Harness](/glossary/harness.md) - the agent runtime a skill is installed into; it loads SKILL.md instructions from its skill directory
- [Skill](/glossary/skill.md) - a directory-rooted capability bundle defined by a SKILL.md entry file; the unit this library stores and distributes
- [Skill dependency](/glossary/skill-dependency.md) - a runtime requirement from one skill to another
