# skills knowledge bundle

An Open Knowledge Format (OKF) v0.1 bundle. Lifecycle policy:
[/conventions/documentation.md](/conventions/documentation.md).

## Repo-wide

- [Decisions](/decisions/index.md) - durable architectural choices and their trade-offs
- [Conventions](/conventions/index.md) - repo-wide prescriptive rules
- [Glossary](/glossary/index.md) - repo-wide domain terms
- [Specifications](/specs/index.md) - contracts of repo-wide utilities (skill installer) and the platform's locked specification
- [References](/references/index.md) - external material mirrored as concepts

## Subsystems

- [docs-setup](/docs-setup/index.md) - skill that installs, upgrades, reinstalls, or repairs OKF v0.1 docs machinery in target repos, distributed by copy from `skills/docs-setup/`
- [superpowers](/superpowers/index.md) - process-meta records (session handoffs) retained from Superpowers-driven work
